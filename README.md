# VEZDEHOT

Мобильная игровая платформа с ботами, локальными комнатами и карточными играми.

## Сейчас работает

- **Дурак** — партия против 1–3 ботов с выбором сложности.
- **Бункер** — ты и 5 ботов, 6 характеристик, раскрытие по раундам, голосование, 3 места и награда +150 чистыми.
- **Покер** — Texas Hold'em против трёх ботов: префлоп, флоп, тёрн, ривер, fold/check/call/raise и showdown.
- **Мафия** — соло-режим против шести ботов: случайная роль, ночь/день, действия мафии, комиссара и доктора, голосование и раскрытие ролей.
- **Монополия** — компактная настольная партия против трёх ботов: бросок кубика, покупка улиц, аренда, шанс, налоги и банкротство.
- PWA-оболочка, мобильные touch-зоны, reduced motion, подсказки, анимации и локальное сохранение.

Все пять режимов уже доступны из лобби. Серверные движки подключаются через общий контракт комнат.

## Архитектура

Пока клиент — быстрый статический MVP в `dist/`, чтобы игра открывалась по ссылке без установки. Игровая логика отделяется от UI по следующему контракту:

```text
GameEngine
├── DurakEngine
├── BunkerEngine
├── PokerEngine
├── MafiaEngine
└── MonopolyEngine

state · legalActions · applyAction · botMove · serialize · restore
```

Supabase project `vezdehot` хранит профили и заготовку серверных комнат/событий. Профиль синхронизируется через anonymous auth с RLS, а клиент продолжает работать локально, если сеть недоступна.

## Запуск

```bash
python3 -m http.server 4173 --directory dist
```

Открой `http://localhost:4173`. Для полноценного online-режима следующий шаг — сервер authoritative realtime для `game_sessions` и `game_events`.

## Проверка

```bash
python3 - <<'PY'
from pathlib import Path
Path('/tmp/vezdehot.js').write_text(Path('dist/index.html').read_text().split('<script>')[1].split('</script>')[0])
PY
node --check /tmp/vezdehot.js
```


## Дурак: спокойный стол (октябрь 2026)

- Постоянные узлы карт: выбор не перерисовывает экран и не запускает раздачу заново.
- Шесть позиций для пар атаки и защиты, отдельная рука с прокруткой, видимый козырь и счётчик отбоя.
- Ручное продолжение после ответа и перед очисткой стола; пауза и три темпа ботов.
- Таймер привязан к текущей партии; при выходе и скрытии вкладки он отменяется. Сохранённый ход возобновляется после загрузки.
- Взятие пропускает защитника, закончившие игроки выходят из круга, проигрывает последний с картами; предусмотрена ничья.
- Вариант правил: подкидывает только основной атакующий; переводов и подкидывания после объявления взятия нет. Профиль и монеты остаются тренировочными, без денежных выплат.
- Обновление кэша не перезагружает активную партию. Стили стола написаны самостоятельно без внешних игровых ассетов.

Автоматические проверки: `node tests/durak-engine.cjs` и `node tests/durak-ui.cjs`. Они включают 150 полных партий, проверку сохранности колоды, пауз, старых сохранений и однократного начисления результата. Проверено в браузере: выбор карты без повторной раздачи, отбивка, взятие, ручное продолжение и адаптивная компоновка при ширине 320 и 390 пикселей. Дополнительные 180 партий и регрессия устаревшего таймера: `node tests/durak-regression.cjs`. При скрытии вкладки партия ставится на паузу; продолжение — по кнопке.
